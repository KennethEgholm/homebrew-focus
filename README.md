# Homebrew tap for Focus – Menu Bar Timer

```sh
brew tap kennethegholm/focus
brew trust kennethegholm/focus
brew install --cask focus-menu-bar-timer
```

Homebrew asks you to trust third-party taps once (`brew trust`). Update later with `brew upgrade --cask focus-menu-bar-timer`.

Prefer the App Store? `brew install mas && mas install 6833000003`, or [open it in the App Store](https://apps.apple.com/app/id6833000003).
